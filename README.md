# StandByDroid

iOS-style dock for Android built with React Native.

## Features
- Clock, Battery, Calendar, Music widgets
- Movable & resizable boxes
- Custom fonts
- Burn-in protection
- Skin system

## Installation
- npm install
- npx react-native run-android

## Contributing
You can add new skins by creating a new file in the faces folder and registering it in FacesMap.
